# whiskey

Whiskey is a static site generator written in Go.

## Commands
```
Usage:
  whiskey [command]

Available Commands:
  build       Build the site
  check       Validate site configuration
  clean       Clean generated artifacts
  completion  Generate the autocompletion script for the specified shell
  help        Help about any command
  serve       Start a local development server
  version     Version information about whiskey

Flags:
  -h, --help   help for whiskey

Use "whiskey [command] --help" for more information about a command.
```
